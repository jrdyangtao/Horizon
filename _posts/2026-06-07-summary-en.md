## [TinyTPU: Interactive Systolic Array Visualization Compiles SystemVerilog to WebAssembly](https://www.reddit.com/r/MachineLearning/comments/1txvvo4/tinytpu_systemverilog_systolic_array_compiled_to/) ⭐️ 8.0/10

TinyTPU is an open-source educational tool that compiles a 4×4 weight-stationary systolic array, written in SystemVerilog, to WebAssembly, enabling a live, step-by-step visualization of matrix multiplication directly in the browser, with RTL behavior verified against NumPy. This bridges the gap between hardware architecture theory and practice by providing an accurate, interactive simulation of how TPUs execute matrix operations, making complex concepts like weight-stationary dataflow, diagonal skew, and partial sum accumulation intuitive for students, engineers, and AI practitioners. The visualization operates at three levels: a single MAC cell, the full 4×4 array, and tiling for larger matrices. All on-screen activity is driven by the compiled RTL state, ensuring a faithful representation of the hardware. The project is open-source under the MIT license.

reddit · r/MachineLearning · /u/Horror-Flamingo-2150 · Jun 5, 20:05

**Background**: Systolic arrays are parallel computing architectures where data flows rhythmically through a grid of processing elements, similar to blood pulsing through veins. Weight-stationary dataflow is a strategy where weights remain fixed in processing elements while activations stream through, reducing data movement and improving energy efficiency—a key principle behind Google's TPU. SystemVerilog is a hardware description language used to design and verify digital circuits. WebAssembly allows low-level code to run in browsers at near-native speed.
